# Sales & Order Management (SQL Project)

## 📌 Project Overview
The **Sales & Order Management System** is an end-to-end SQL project designed to demonstrate strong database design and querying skills.  
The project manages customers, products, orders, payments, and inventory using a well-structured relational database.

This project is created to showcase **real-world SQL developer skills** such as normalization, joins, stored procedures, views, and performance optimization.

---

## 🎯 Project Objectives
- Design a normalized relational database (up to **3NF**)
- Implement **primary keys, foreign keys, and composite keys**
- Write **complex SQL queries** for business insights
- Create **views and stored procedures**
- Optimize performance using **indexes**
- Follow **industry-level SQL project structure**

---

## 🗂 Database Schema & Tables
The database consists of the following tables:

- `customers` – Stores customer details  
- `products` – Stores product information  
- `orders` – Stores order-level data  
- `order_items` – Stores product details per order (Composite Key)  
- `payments` – Stores payment information  
- `inventory` – Tracks stock quantity for each product  

---

## 🔗 Table Relationships
- One customer → Many orders  
- One order → Many products  
- One product → One inventory record  
- Orders linked with payments
